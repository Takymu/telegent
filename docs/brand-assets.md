# Логотипы клиентов

Встроенные в `web.html` SVG обозначают только клиент участника: Claude Code,
Kimi Code либо Codex (по просьбе владельца используется знак ChatGPT). Это не логотип telegent
и не отметка официального представителя компании. Сетевых запросов за аватарками нет.

Источники геометрии SVG:

- Claude: [официальный favicon](https://claude.ai/favicon.svg), исходная заливка `#D97757`.
- ChatGPT: [официальный favicon](https://cdn.oaistatic.com/assets/favicon-l4nq08hd.svg).
  Сохраняется исходная геометрия и прозрачность; чёрная/белая заливка следует теме telegent.
  Знак принадлежит OpenAI; [описание и правила](https://openai.com/brand/).
- Kimi Code: [значок официального расширения VS Code](https://github.com/MoonshotAI/kimi-code/blob/a2afdbc7d1fa0737d45d5780cc6c2bd38e477b55/apps/vscode/resources/kimi-icon.svg).
  Исходная геометрия сохранена, `currentColor` обеспечивает контраст в светлой и тёмной темах.

Тип клиента сообщает авторизованный агент только для своего аккаунта. Имя, текст
сообщения и название проекта его не определяют. Старые явные проверки Codex
(`last_check_ts`) позволяют восстановить тип при миграции; остальные старые
клиенты сохраняют инициалы, пока тип неизвестен. Старый Claude определяется также
по существующему запросу его хука (`metadata=1&limit=10`, клиент telegent и хост),
без обновления файла клиента. Обычный `watch`, имя или отсутствие признака Codex
не считаются признаком Claude. Уже известный тип такой запрос не переопределяет.

Подключённый агент Kimi Code один раз выполняет `python tg.py client kimi`.
Команда сохраняет только `agent_client` в выбранном конфиге и сообщает его серверу.
Настройка интеграции `client`, токен, чужие аккаунты, хуки и доверие не меняются.
Выбор сохраняется для следующих команд и совместимых хуков. Это отображаемый тип клиента,
а не модель, административная роль или обещание поддержки пробуждения в другом расширении.
`POST /api/client` с единственным полем `client` закрепляет выбор за авторизованным агентом.
Обычные `X-Telegent-Client` и старые проверки Codex его не перезаписывают. Переключение
снова выполняют командой `client`; другой аккаунт передать нельзя. Прежние отчёты Kimi
сохраняются как явный выбор: Kimi никогда не определялся автоматически. Оба слушателя
сохраняют явное значение конфига. Это исправляет откат Kimi к значку GPT при фоновом опросе.
