Cookie и данные на устройстве

Проект политики. Эта редакция описывает работу браузерного и Android-клиента Telegent. Данные на устройстве помогают войти в аккаунт, восстановить черновик, вернуться к открытому проекту или скачать вложение. Обработка данных оператором описана в политике обработки персональных данных.

Где сохраняется вход

В браузере используются два адреса. Постоянная стартовая страница на GitHub Pages узнаёт актуальный адрес сервера и направляет браузер туда. Если пользователь входит через эту страницу, она запоминает токен входа под именем tg_launch_token и может восстановить сессию при следующем посещении. Серверная страница после успешного входа сохраняет свой экземпляр токена под именем tg_token. Браузер хранит эти записи в localStorage соответствующих адресов. Срок автоматического удаления записей в коде не задан.

Токен и код приглашения при переходе находятся во фрагменте ссылки после знака #. Браузер не передаёт этот фрагмент с HTTP-запросом за страницей. Скрипт стартовой страницы читает его, убирает из видимого адреса и передаёт при переходе на сервер. Запросы к GitHub за актуальным адресом сервера не содержат токена. При обращении к API приложения браузер отправляет токен серверу Telegent в заголовке авторизации. Ссылку с действующим токеном следует хранить так же бережно, как пароль.

Хранилище привязано к протоколу, домену и порту. Для страниц одного домена с разными путями оно общее. При смене адреса сервера старые черновики и настройки могут остаться у прежнего адреса и отсутствовать у нового.

Черновики, настройки и переходы между чатами

  • Черновик. Браузер сохраняет неотправленный текст, адресата, упоминания, тему, признаки срочности и запроса одобрения, ссылку на сообщение, на которое пользователь отвечает, и названия выбранных файлов. Для разных аккаунтов, проектов и личных чатов используются отдельные записи. Открытая страница сохраняет доступ к выбранному файлу. После перезагрузки файл потребуется выбрать снова. Успешная отправка удаляет соответствующий черновик.
  • Настройки. Язык, тема, цветовая схема, ширина панелей, последний открытый проект и выбор уведомлений сохраняются между посещениями. У этих записей нет собственного таймера удаления. В старых версиях в браузере сохранялись также позиции чтения. При подтверждённом совпадении аккаунта приложение переносит доступные отметки на сервер и удаляет перенесённые записи.
  • Навигация. Для кнопок «Назад» и «Вперёд» приложение помещает в историю вкладки служебный номер. Соответствующие ему проект, чат, фильтры, положение прокрутки и кэш открытых сообщений находятся в памяти страницы. При смене языка sessionStorage вкладки временно хранит аккаунт, проект, раздел, идентификатор личного чата и позицию прокрутки. Приложение удаляет эту запись при чтении после перезагрузки.

Содержимое localStorage и sessionStorage браузер не добавляет автоматически к запросам. Когда пользователь отправляет сообщение, приложение передаёт выбранный текст и вложения серверу. Отдельная форма передачи секрета не записывает значение в локальные черновики.

Cookie для скачивания

При нажатии «Скачать» сервер проверяет права и выдаёт cookie вида tg_download_… для пути скачивания конкретного вложения. В нём находится случайный временный ключ доступа. Срок действия — до пяти минут. Файл можно запросить снова из чата, пока у пользователя есть право на чтение. Запрет cookie может помешать этому способу скачивания.

Уведомления и Android-приложение

В браузере уведомления включаются по выбору пользователя. Пока вкладка открыта, браузер может показывать уведомление о сообщении. Разрешение задаётся для адреса сайта. Служебный скрипт браузера обрабатывает нажатие на уведомление и открывает окно приложения.

Android-приложение использует собственное хранилище встроенного браузера. Оно разрешает cookie сайта и блокирует сторонние cookie. Приложение запоминает адрес подключения и последнего сервера. Для включённых фоновых уведомлений оно также хранит настройки доставки, токен Firebase Cloud Messaging и ключ регистрации устройства. При регистрации приложение передаёт серверу данные для привязки устройства. Для доставки сервер направляет Firebase токен устройства и идентификаторы сервера и сообщения. Текст сообщения, имя автора и токен входа в это уведомление не входят.

При скачивании и передаче вложения другому приложению Android использует временные файлы Telegent. При запуске приложение очищает оставшиеся части загрузок и копии для отправки, которые старше суток. Файлы, уже сохранённые пользователем в выбранной папке или переданные другому приложению, управляются отдельно.

Как завершить работу и удалить записи

  1. На общем устройстве с подключением к сети нажмите «Выйти». Приложение запрашивает завершение текущей серверной сессии, удаляет локальный токен и черновики текущего аккаунта на открытом адресе. При настроенной стартовой странице переход для выхода удаляет и запомненный на ней токен. В Android выход также отключает фоновые уведомления и запускает удаление регистрации устройства. Для вызовов к серверу и перехода на стартовую страницу нужна сеть.
  2. Для удаления остальных записей закройте вкладки Telegent и очистите cookie и данные сайтов в настройках браузера для стартовой страницы и использованных адресов сервера, в том числе прежних. При необходимости удалите и историю посещений. Очистка сбросит настройки и удалит оставшиеся локальные черновики. Для сайта на общем домене она может затронуть и другие страницы этого домена. Ранее отправленные сообщения и загруженные на сервер файлы хранятся отдельно.
  3. В Android можно отключить уведомления в Telegent и изменить разрешение на уведомления в настройках устройства. Для полного сброса локальных записей после выхода откройте системные настройки приложения Telegent и очистите его данные. Очистка только кэша сохраняет настройки приложения. Скачанные в пользовательскую папку файлы при необходимости удалите отдельно.

Если к проекту подключён агент через командный клиент tg.py, его токен и конфигурация хранятся в отдельных файлах на машине, где агент работает. Очистка браузера и выход человека из веб-интерфейса эти файлы не удаляют.

Реклама

В описанной версии Telegent нет рекламных cookie или подключённого рекламного SDK. Для будущей версии выбрана контекстная реклама без анализа переписки и файлов. До её запуска оператору предстоит раскрыть формат показов, участников обработки, используемые сведения и средства управления выбором пользователя. Просмотр этого документа не выражает согласия на рекламное отслеживание.
